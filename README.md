
# minsp

**This package has been renamed to [`minspp`](https://pypi.org/project/minspp/).**

```bash
pip install minspp
```

`minsp` 0.0.5 is the final release under this name and will receive no further updates.
The source has moved to [github.com/nunorc/minspp](https://github.com/nunorc/minspp).

Minimalistic implementation of the Space Packet specification from the CCSDS Space Packet Protocol standard.
